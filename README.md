## The line

> My Roomba left me for a neighbor who actually picks things up.

## Run

```sh
ENTRY_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (stdlib only, no network) writes exactly one line to `$ENTRY_OUTPUT_DIR/entry.txt`.
